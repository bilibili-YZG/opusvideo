【玻璃温室 / The Glasshouse】文件放置说明

请把本作品的文件放在这个文件夹内：

02_the_glasshouse/
├── index.html                 本作品独立详情页（不要移动）
├── video.mp4                  ← 把最终成片放这里，必须命名 video.mp4
├── prompt.txt                 ← 把本作品完整提示词放这里
├── project.zip                ← 可选：把可下载工程打包成 project.zip
└── project/                   ← 可选：未打包的工程源文件放这里

注意：
1. 视频必须命名为 video.mp4，建议 H.264 + AAC 编码。
2. 提示词必须命名为 prompt.txt（网页展示的提示词内容在 assets/js/works.js 修改）。
3. 工程下载按钮对应 project.zip；若暂时没有工程，可以先不放。
4. 详情页和整个目录结构请保持原样，避免相对路径失效。
